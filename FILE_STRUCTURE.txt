Interface Connections
=====================

USB CDC Serial (Debug)
    ↓
RP2350A (Main MCU)
    │
    ├─→ SPI0 (GP16-19) ──→ Tesla BMS Modules
    │
    ├─→ I2C0 (GP4-5) ───→ INA228 Current Sensor
    │
    ├─→ ADC0-3 (GP26-29) ─→ Voltage Dividers (400V→3V)
    │
    ├─→ UART0 (GP0-1) ───→ ESP32-S3 ESPHome Display
    │
    └─→ PWM (GP20-21) ───→ Contactor Drivers
